## Fase 1: 🏗️ Fondasi Template Data-Driven

Status: **AKTIF — dimulai dari halaman jasa kota** | Prioritas: #1

Tujuan: ubah 33 file raksasa copy-paste → sistem template terpusat. Edit 1 tempat = berubah semua.

Urutan eksekusi dalam Fase 1 (keputusan pemilik):
1. **Halaman jasa kota** (`/jasa/bore-pile/{jakarta,bandung,bekasi,bogor,depok,karawang,semarang,surabaya,tangerang}.html`) — 9 halaman
2. **Halaman harga diameter** (`/harga/bore-pile-{30,40,50,60,80}cm.html`) — 5 halaman
3. Tipe lain menyusul: galeri, artikel, area flat, dll.

### Pekerjaan Detail

**1A. Konsolidasi Layout & Komponen Global**
- Semua halaman memakai `BaseLayout.astro`
- Navbar, Footer, WhatsApp Float → komponen Astro tunggal (bukan inline per halaman)
- `<head>` (meta, OG, schema dasar) → dikelola BaseLayout
- Nomor WA diseragamkan ke 6285710277854 dari config.json

**1B. Template Halaman Kota Bore Pile (9 halaman) — SEDANG INI**
- 1 template dinamis untuk 9 kota
- Semua data kota dari JSON (konten panjang per kota harus diekstrak dari file .astro mandiri ke data dulu — `borepile-kota.json` saat ini hanya berisi metadata ringkas)
- Kalkulator harga → komponen reusable, baca dari harga.json
- Tabel harga → komponen, baca dari harga.json
- FAQ → dari data JSON per kota
- Schema JSON-LD → generate otomatis dari data
- Hapus file kota mandiri setelah template terverifikasi

**1C. Template Halaman Area Flat (8 halaman)** — menyusul
**1D. Template Halaman Harga Diameter (5 halaman)** — menyusul; angka masih hardcode (35–39 literal Rp per file)
**1E. Koneksi Data Menganggur** — galeri.json belum dipakai halaman galeri

### Standar Konten Anti-Slop (kunci sejak desain skema data)

Halaman baru/hasil template harus langsung bersih dari pola AI-slop:
- FAQ benar-benar unik & relevan per kota (bukan ganti nama doang)
- Paragraf konteks wilayah spesifik (bukan "kota X berkembang pesat")
- Tanpa ikon/emoji dekoratif fungsional-mati
- Internal linking bervariasi (jangan semua halaman menampilkan blok artikel sama persis — saat ini 28/33 halaman identik)
- Foto proyek asli per halaman
- Maps + keterangan "Kantor pusat Jakarta, melayani wilayah [Kota]"

### Verifikasi Fase 1
- `npm run build` sukses, jumlah halaman tetap
- Output HTML identik secara konten/SEO dengan sebelumnya (title/desc/canonical/h1/heading/schema) — alat: `tools/verify-renovasi.ps1` + diff teks
- Visual tidak berubah (masih legacy)

## Fase 2: 🗺️ Ekspansi Local SEO — MENUNGGU FASE 1
Halaman kota/area baru seluruh Jawa; karena template sudah jadi, proses = tambah data JSON. Tiap halaman baru minimal 40–50% konten unik (foto proyek, kondisi tanah & rekomendasi diameter, akses logistik). Update sitemap.xml + robots.txt, submit GSC.

## Fase 3: ✍️ Anti AI-Slop Halaman Lama — MENUNGGU FASE 2
Bersihkan elemen generik/template-an di halaman existing yang tidak lewat template (audit konten per halaman, FAQ unik per kota, paragraf wilayah spesifik, diversifikasi internal link, foto asli).

## Fase 4: ⚡ Performa & Audit Teknikal — SEBAGIAN BESAR SUDAH BERJALAN
Pilot optimasi 2 halaman (FA→SVG inline + GTM defer) sudah selesai & terverifikasi 2026-08-25 — lihat seksi "Optimasi performa" di AGENTS.md. Sisa pekerjaan fase ini:
- Rollout pola SVG/GTM ke halaman lain dilakukan **lewat template** (bukan edit manual satu-satu)
- Optimasi gambar: `public/imgs/bore-pile-semarang.png` 1,9 MB PNG → WebP (satu file ini > total CSS situs)
- Audit PageSpeed/CWV setelah template jalan
- Catatan teknis: minify/dead-code CSS legacy TIDAK dikerjakan (Brotli hosting sudah cukup; risiko visual > manfaat) — CSS akan ditulis ulang saat redesign

## Fase 5: 🎨 Redesign Modern — TERAKHIR
Modern & clean, tanpa dependency baru, kalkulator tetap fitur utama, SEO/konten identik saat ganti kulit.
